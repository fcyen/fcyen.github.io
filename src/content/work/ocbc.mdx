This was a coursework for the UX Bootcamp by Vertical Institute. The project investigates the user experience of the app's Payment & Transfer functionality. \
Beginning with competitor analysis and user interviews, I've identified gaps in the current experience. \
Based on these insights, I developed an enhanced user journey aimed at addressing key pain points and improving usability.
